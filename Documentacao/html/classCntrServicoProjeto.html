Descrição detalhada

Implementação concreta dos serviços de negócio relacionados a Projeto.

Implementa a interface IServicoProjeto e aplica as regras de permissão (GESTOR).

◆ atualizar()

bool CntrServicoProjeto::atualizar ( const Email & usuario,
const Identificador & identificador,
const Projeto & projeto )
overridevirtual

Substitui nome, descrição, início e término de um projeto cadastrado.

O identificador presente em projeto seleciona o registro existente e deve ser preservado, pois a chave primária não pode ser editada.

Pré-condição
O solicitante deve estar autenticado com papel GESTOR.
Parâmetros
[in]usuarioEndereço eletrônico do solicitante autenticado.
[in]identificadorCódigo que identifica o projeto a ser alterado.
[in]projetoCódigo do registro existente e novos valores dos dados editáveis.
Retorna
true se os dados forem atualizados; false se o registro não existir ou a atualização não puder ser realizada.
