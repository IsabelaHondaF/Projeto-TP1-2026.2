Hierarquia de Classes
Esta lista de hierarquias está parcialmente ordenada (ordem alfabética):
 CBancoDadosGerencia a conexão com o banco de dados relacional SQLite do sistema
 CCartaoDeAtividadeRepresenta um cartao de atividade de um quadro Kanban
 CCntrApresentacaoPrincipalControladora principal da apresentação: tela inicial, sessão e menu principal
 CContainerCartoesPersistência em banco de dados relacional SQLite de cartões de atividade e seus vínculos
 CContainerPessoasPersistência em banco de dados relacional SQLite das pessoas cadastradas
 CContainerProjetosPersistência em banco de dados relacional SQLite de projetos e seus respectivos gestores
 CContainerQuadrosPersistência em banco de dados relacional SQLite de quadros Kanban e seus vínculos com projetos
 CEmailArmazena o endereço eletrônico utilizado para identificar uma conta no sistema
 CEstadoIdentifica a etapa de execução de uma atividade no quadro Kanban
 CFimDeEntradaExceção lançada quando a entrada padrão termina (fim de arquivo)
 CIApresentacaoPessoaInterface de apresentação de contas e autenticação (IAA)
  CCntrApresentacaoPessoaControladora de apresentação dos serviços relacionados a Pessoa
 CIApresentacaoProjetoInterface de apresentação da gestão de projetos (IAP)
  CCntrApresentacaoProjetoControladora de apresentação dos serviços relacionados a Projeto
 CIApresentacaoQuadroInterface de apresentação da gestão de quadros e seus cartões (IAQ)
  CCntrApresentacaoQuadroControladora de apresentação de quadros, cartões e métricas
 CIdentificadorArmazena o código utilizado como chave primária de projetos, quadros e atividades
 CIServicoPessoaDefine operações para cadastrar contas, verificar credenciais e consultar usuários
  CCntrServicoPessoaImplementação concreta dos serviços de negócio relacionados a Pessoa
 CIServicoProjetoDefine operações para cadastrar e manter conjuntos de atividades e seus períodos
  CCntrServicoProjetoImplementação concreta dos serviços de negócio relacionados a Projeto
 CIServicoQuadroInterface dos serviços de quadros e cartões do subsistema Quadro (ISQ)
  CCntrServicoQuadroImplementação dos serviços de quadros e cartões do subsistema Quadro
 CLimiteRepresenta a quantidade máxima de atividades simultâneas na coluna FAZENDO
 CNomeArmazena o nome de uma pessoa, projeto, quadro ou atividade
 CPapelIdentifica a função de um usuário para a definição de suas permissões no sistema
 CPessoaRepresenta uma pessoa cadastrada no sistema
 CPrioridadeClassifica a preferência de atendimento de uma atividade
 CProjetoRepresenta um projeto cadastrado no sistema
 CQuadroRepresenta um quadro Kanban
 CRegistroCartaoRegistro interno que vincula um cartão ao quadro e ao desenvolvedor responsável
 CRegistroProjetoRegistro interno que vincula um projeto ao gestor responsável
 CRegistroQuadroRegistro interno que vincula um quadro ao projeto pai
 CSenhaArmazena a sequência de caracteres usada para comprovar o acesso a uma conta
 CTamanhoClassifica a dimensão do trabalho de uma atividade
 CTesteUnitarioBaseClasse base de suporte para testes unitários com contagem de asserções
  CTUCartaoDeAtividadeTeste de unidade para a entidade CartaoDeAtividade
  CTUEmailTeste de unidade para o domínio Email
  CTUEstadoTeste de unidade para o domínio Estado
  CTUIdentificadorTeste de unidade para o domínio Identificador
  CTULimiteTeste de unidade para o domínio Limite
  CTUNomeTeste de unidade para o domínio Nome
  CTUPapelTeste de unidade para o domínio Papel
  CTUPessoaTeste de unidade para a entidade Pessoa
  CTUPrioridadeTeste de unidade para o domínio Prioridade
  CTUProjetoTeste de unidade para a entidade Projeto
  CTUQuadroTeste de unidade para a entidade Quadro
  CTUSenhaTeste de unidade para o domínio Senha
  CTUTamanhoTeste de unidade para o domínio Tamanho
  CTUTextoTeste de unidade para o domínio Texto
  CTUTimestampTeste de unidade para o domínio Timestamp
 CTextoArmazena uma descrição curta de um projeto ou de uma atividade
 CTimestampArmazena um instante no tempo composto por data e horário
