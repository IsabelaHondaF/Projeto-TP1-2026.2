Descrição detalhada

Define operações para cadastrar contas, verificar credenciais e consultar usuários.

O endereço eletrônico identifica cada conta. A criação e a autenticação precedem o acesso aos demais serviços, disponíveis a usuários autenticados com papel GESTOR ou DESENVOLVEDOR. As implementações devem preservar a chave primária nas atualizações e a consistência dos vínculos nas exclusões.

Observação
Nos métodos com saída por referência, o resultado deve ser utilizado somente quando o retorno for true.

◆ atualizar()

virtual bool IServicoPessoa::atualizar ( const Email & usuario,
const Email & alvo,
const Pessoa & pessoa )
pure virtual

Substitui os dados editáveis de uma conta já cadastrada.

O endereço eletrônico presente em pessoa seleciona o registro existente e deve ser preservado. Nome, senha e papel compõem os dados atualizáveis.

Pré-condição
O solicitante deve estar autenticado como GESTOR ou DESENVOLVEDOR.
Parâmetros
[in]usuarioEndereço eletrônico do solicitante autenticado.
[in]alvoEndereço eletrônico da conta a ser alterada.
[in]pessoaEndereço eletrônico da conta existente e novos dados editáveis.
Retorna
true se os dados forem atualizados; false se a conta não existir ou a atualização não puder ser realizada.
Exceções
std::runtime_errorSe ocorrer falha no acesso ao armazenamento de dados.

Cadastra uma conta para permitir o acesso do usuário ao sistema.

Esta operação não exige autenticação prévia. O endereço eletrônico fornecido identifica a nova conta e não pode duplicar uma conta existente.

Parâmetros
[in]pessoaDados de cadastro: endereço eletrônico, nome, senha e papel.
Retorna
true se a conta for cadastrada; false se não for possível cadastrá-la.
