Descrição detalhada

Identifica a etapa de execução de uma atividade no quadro Kanban.

Aceita A FAZER para trabalho ainda não iniciado, FAZENDO para trabalho em andamento e FEITO para trabalho concluído. Os valores devem ser escritos exatamente dessa forma, com letras maiúsculas. A validação verifica o valor informado.
