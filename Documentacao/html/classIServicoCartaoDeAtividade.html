Descrição detalhada

Interface responsável pelos serviços relacionados a cartões de atividade.

Define as operações disponibilizadas pela camada de serviço para criação, leitura, atualização, exclusão, listagem e movimentação de cartões, além do cálculo das métricas de tempo do quadro Kanban.

A implementação deve controlar as movimentações entre A FAZER, FAZENDO e FEITO e respeitar o limite de WIP do quadro.

Atualiza os dados editáveis de um cartão de atividade.

O identificador contido no cartão é utilizado para localizar a entidade armazenada e não deve ser alterado.

A alteração do estado e dos instantes relacionados às movimentações deve ser realizada pelo serviço mover.

[in]identificadorIdentificador do cartão que será atualizado.
[in]cartaoEntidade contendo os novos dados do cartão.
Retorna
true caso a atualização seja realizada com sucesso.
false caso a operação não possa ser realizada.

◆ mover()

virtual bool IServicoCartaoDeAtividade::mover ( const Email &  usuario,
const Identificador &  identificador,
const Timestamp &  instante 
)
pure virtual

Move um cartão para a próxima coluna permitida do quadro.

As únicas movimentações permitidas são:

A FAZER -> FAZENDO FAZENDO -> FEITO

Ao entrar em FAZENDO, a implementação deve registrar o instante de início e respeitar o limite de WIP do quadro.

Ao entrar em FEITO, deve registrar o instante de término.

Parâmetros
[in]usuarioEmail do usuário que solicita a movimentação.
[in]identificadorIdentificador do cartão que será movido.
[in]instanteMomento em que ocorre a movimentação.
Retorna
true caso a movimentação seja realizada.
false caso a movimentação não seja permitida.
