Descrição detalhada

Interface responsável pelos serviços relacionados à entidade Quadro.

Define as operações disponibilizadas pela camada de serviço para criação, leitura, atualização, exclusão e listagem de quadros.

O vínculo entre um quadro e um projeto deve ser mantido pela camada de serviço.
